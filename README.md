## What I work on

I'm a Ph.D. researcher at the University of Cincinnati working on **trustworthy machine
learning** — making model behavior predictable, auditable, and safe to depend on.

- **Learning dynamics & influence analysis** — per-update gradient tracing to attribute model
  behavior back to the individual training updates that caused it
- **RLHF & preference optimization** — controlled fine-tuning experiments that localize where
  unsafe behavior forms in preference-based pipelines
- **LLM security** — jailbreaks, data poisoning, and governance tooling for third-party agent
  extensions (static analysis, permissions, sandboxed runtime evaluation)

Alongside the research I build production ML and full-stack systems — computer vision
pipelines, agentic workflows, and cloud data platforms.

> Currently also a part-time Research Assistant at the **P&G Digital Accelerator**.
